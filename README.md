The World in One Day — a broadsheet front page that sums up the world news of Wednesday, 18 November 2026 in a single 1024 × 1024 image. `render.py` typesets and draws the whole page in code with Pillow from a fixed news brief: masthead, world map with story pins, market strip, and briefs in a strict column grid with hairline rules — no downloaded assets, fully deterministic. The graded entrypoint `main.py` uses only the Python standard library: it copies the committed `entry.png` into the output directory.

## Run it

```sh
python3 main.py
```
